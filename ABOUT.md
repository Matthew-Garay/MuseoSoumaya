# Museo Soumaya Sitio Web

## Acerca de

Sitio web informativo desarrollado con PHP 8.2 que incluye secciones de galerias, colecciones, exposiciones, quienes somos, contacto y arte para todos. Presenta contenido institucional del museo de forma estatica y navegable, sin requerimiento de base de datos. Sitio web de contenido estatico ejecutado en un servidor local Apache mediante XAMPP, utilizando PHP puro para la renderizacion de secciones.

## Caracteristicas principales

- Navegacion entre secciones: galerias, colecciones, exposiciones, quienes somos, contacto y arte para todos.
- Backend desarrollado con PHP 8.2 puro.
- Frontend construido con HTML5, CSS3 y JavaScript.
- Estilos mediante Bootstrap 5 y Tailwind CSS a traves de CDN.
- Servidor local Apache ejecutado con XAMPP.
- Sin base de datos ni persistencia de datos.

## Stack tecnologico

| Categoria | Tecnologia |
|-----------|------------|
| Backend | PHP 8.2 |
| Frontend | HTML5, CSS3, JavaScript |
| Estilos | Bootstrap 5 (CDN), Tailwind CSS (CDN) |
| Servidor local | Apache (XAMPP) |
